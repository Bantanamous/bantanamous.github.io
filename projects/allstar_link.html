Allstar link Repeater

This project is a simple Allstar link simplex node that can extend the range of Allstar network connections. It is designed to receive signals from one Allstar node and retransmit them to another, effectively creating a bridge between two separate Allstar networks.

What it does

This project extends the range of Allstar network connections by receiving signals from one node and retransmitting them to another. A goal for the future is to implement full repeater capabilities and permanently install it in Arizona.

Basic commands

  • *70 -- To check the status of the node (See if the node is connected to other nodes)
    • *806 -- Disconnects connected nodes. Do this before connecting a new node. *1 [node number] -- Disconnects a specific node number *3 [node number] -- Connects to a node number (DO NOT CONNECT TO A NODE WITHOUT DISCONNECTING FROM ALL OTHER CONNECTED NODES)

    Tools / Technologies

    • RA 25 Audio Interface
